# CombatSolver 0.47.2

## 简体中文

- 新增《杀戮尖塔 2》v0.111.0 手机版预览支持：战斗中可搜索并全自动执行路线，界面改为更易触控的布局。
- 适配“更好的故障机器人”v0.11.66 的已审阅卡牌与改造效果；修复“发现”进入牌组后的计算错误，以及燃料在压缩改造前后的预测偏差。
- 修复未改造堆栈和螺旋钻击的效果预测。未知模组效果仍会保护性停止计算，不会强行自动出牌。
- 手机版搜索新增 4 GB 托管堆软预算，内存栏分别显示进程占用与本次搜索新增内存。该数值不是设备可用内存或严格进程上限。

## English

- Added a preview for the mobile game v0.111.0, with combat search, full-auto route execution, and larger touch controls.
- Added prediction support for reviewed BetterDefect v0.11.66 cards and transformations. Fixed search failures involving Discovery and the different Fuel effects before and after the Compact transformation.
- Fixed prediction for untransformed Stack and Helix Drill. Unknown mod effects still stop search and automatic play conservatively.
- Added a 4 GB managed-heap soft budget for mobile search. The memory display now separates process usage from memory added by the current search; this is not a strict process limit or a guarantee of available device memory.
